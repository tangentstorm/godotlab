# godotlab

**godotlab** \u2014 a collection of small Godot 3 experiments: a Collatz-conjecture tile demo with a bit-adder/register (`collatz/`), two tiny movement/shooter prototypes (`game00/`, `game01/` \u2014 the latter with a compiled HTML5 build), Aseprite character art (`sprites/`), and a tilemap sandbox (`tilemap/`). Nothing is finished; the interesting bits are the collatz adder tiles and the working Godot-3-to-web export example.

All of these are playable in the browser at https://tangentstorm.github.io/arcade/ \u2014 but fair warning, they're all pretty dumb.

The sprite art now also lives in [tangentstorm/tangentsprites](https://github.com/tangentstorm/tangentsprites), which has a gallery of the PNGs.
